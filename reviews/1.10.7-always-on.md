## Minor (verified)

1. **[correctness/security-adjacent] Under a manifest, `settled()` scopes only `state-quiet`. Its render and notification signals are global.** `src/agent.ts` ~3510. `pendingRenders()` and `pendingUpdates()` (component.ts:1278-1279) are module-global. A Component re-rendering because of undeclared state therefore does two things on a scoped surface: it delays the resolve, and on timeout it reports `pending.renders: N`. The docs give a reason for scoping state-quiet: waiting on an undeclared path "would disclose that it changed". That same reason applies here. The channel is coarse and timing-only (it reveals that something rendered, not which path or what value), and `notifications` is mostly neutralised by the `await updates()` that runs before it is read. No test covers scoped settled() against render activity from out-of-scope state.
   *Suggested before tagging (cheap):* option (a). Document `component-renders` and `state-notifications` as global even under a manifest, in both the docs table and `notCovered` / `out-of-scope-state`. Then decide (b), which is to drop or booleanize `pending.renders` on scoped surfaces, as a follow-up.

2. **[blast-radius] The long-list warning (>10 items, no `virtual` / `nonVirtualReason`) fires from tosijs-ui internals that downstream authors cannot change, and no tosijs-ui issue has been filed.** `src/list-binding.ts` ~1432. Verification narrowed the impact:
   - The doc-browser flat nav (`doc-browser.js:1175-1183`) warns only in `routing: 'query'`, which applies to direct `createDocBrowser()` callers. `tosijs-ui/site` passes `path`/`memory` routing and is not affected.
   - The reviewer missed one case: `<tosi-table>` with the documented `rowHeight: 0` (`data-table.js:914`), and pinned-row bodies (`data-table.js:2102, 2902`) always pass `{}`. Authors of those tables can silence the warning only with `settings.quiet`.
   The CHANGELOG expects warnings to appear in tosijs-ui. What's missing is the upstream issue that sends the signal to the package that can fix it. This is the same class as tosijs-ui#127.

## Nits (unverified: sanity-check before acting)

3. **[correctness] (unverified)** The docs, the `AgentWiringRecord.key` JSDoc, the `recordKeys` comment and CHANGELOG 1.10.7 all say virtual lists "reuse row elements" and "rewrite binding paths in place". ListBinding actually removes off-screen rows and clones fresh ones, so keys change because the element is replaced. The "RE-TARGETED element" test hand-mutates `dataBindings[0].path`, which simulates a mechanism the library never uses. The behaviour is correct, but the stated rationale is wrong. `src/agent.ts:43`.
4. **[correctness] (unverified)** `settled({ timeout: 40 })` rejects with a message about `quietMs`, which the caller never passed. The cause is the default of 50. Fix by clamping the defaulted quietMs below the timeout, or by naming the default in the message. `src/agent.ts:3458`.
5. **[blast-radius] (unverified)** The no-agent consumer gate writes `tosijs-no-agent-<pid>.ts` to `os.tmpdir()` and removes it only on success. Bun 1.4.2's `Bun.build` throws on failure, so the file leaks. Fix with try/finally, or by writing it into a gitignored scratch dir in the repo. `bin/site.ts:580`.
