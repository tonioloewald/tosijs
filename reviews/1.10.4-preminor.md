## Findings by severity

### Minor

1. **[security, VERIFIED] publish.yml runs unpinned `.practices` code and the whole build/devDependency toolchain in the only job that holds `id-token: write`.** (`.github/workflows/publish.yml:43-72, 190-227`)
   - The job-wide permission covers every step.
   - The `.practices` checkout has no `ref`, and its tools run before Stage.
   - The verifier also found that `steps.pack.outputs.integrity` comes from `$GITHUB_OUTPUT`, which any earlier in-job step can write to. So the post-approval "Verify what shipped" check does not independently vouch for the bytes.
   - Mitigations: 2FA approval of the staged package, the practices repo has the same owner, and the OIDC token is short-lived.
   - Fix upstream in the template: pin `.practices` to a SHA. Split the work into a build/test/pack job with `contents: read` and a minimal stage job that only has `id-token: write`, receives the tarball and its hash as an artifact, and runs no repo code. SHA-pin third-party actions.
2. **[security, VERIFIED] An unattested publish fails closed only by accident.** (`.github/workflows/publish.yml:~187`, practices `tools/release-doctor.ts:161-192, 1049`)
   - The attestation step is `hashFiles(...) != ''`-guarded, so it is skipped when the file is missing.
   - release-doctor records a CANNOT_RUN lane as SKIP and exits 0 on SKIPs.
   - The only thing that makes it fail today is that the job has no TLS cert. Copy ci.yml's throwaway-cert step into publish.yml and Playwright's "Executable doesn't exist" error makes the mandatory browser gate pass without running.
   - Fix upstream: fail when `attestedLanes` is non-empty and the attestation is missing, and treat a SKIP of an attested lane as FAIL under `RELEASE_DOCTOR_PUBLISHING`.
3. **[correctness] (unverified) The real-engine structural lane only covers headings.** `tests/structural-scope.pw.ts` does not cover an `aria-hidden` heading, or a landmark or custom-element container bound to an undeclared path. So the "secrecy and aria-hidden hold unconditionally" claim is green only under a mocked `getBoundingClientRect`.
4. **[blast-radius] (unverified) publish.yml is a frozen byte-copy of the practices template, and nothing detects drift.** The tools also run from unpinned HEAD, so the YAML and the tools can fall out of step in either direction. Template fixes (already 3 revisions) never reach adopters.
5. **[blast-radius] (unverified) The committed `.claude/settings.json` and `.mcp.json` run `virta brief` on SessionStart and UserPromptSubmit for every contributor.** If virta is missing, every prompt produces a hook error. Only CLAUDE.md mentions this. It does not affect npm consumers.

### Nit

6. **[security, VERIFIED, downgraded minor to nit] Under `expose: { roots }`, an *unbound* heading's interpolated text is published even when `read()` refuses the source path.** (`src/agent.ts:~2949-2980`, pinned in `src/agent.test.ts:1387-1418`)
   - This is a deliberate decision, documented in three places.
   - The text is a rendered copy with no path, so scope has nothing to consult.
   - Author controls do exist in code: `h2({'data-tosi-secret': ''}, …)`, `aria-hidden`, or binding the text instead of copying it. The finding's claim that there is "no in-code way" is wrong.
   - What remains: consider a `structureText: 'bound-only'` manifest option before the 1.12.0 `withhold` channel, and repeat the caveat next to the `expose: { roots }` docs.
7. **[security] (unverified) The "heading containing a child bound to an undeclared path" case is unpinned.** A scratch probe shows it behaves correctly (`textWithheld: true`, no text, via `contentWithheld` → `subtreeBindingPaths`), but no test would catch a regression.
8. **[correctness] (unverified) `src/type-surface.test.ts:8` resolves tsc from `process.cwd()`.** Running from `src/` fails with ENOENT. All current callers run from the repo root.
9. **[efficiency] (unverified) The build prints no per-phase wall-clock time,** so build-time growth can only be seen by timing it by hand. Build time was not measured in this read-only review.
10. **[blast-radius] (unverified) The `npx tsc` → local-tsc fix and the once-per-process-latch test seam are not in the shared KB.** The next adopter of publish.yml will rediscover the macOS-green / Linux-red failure.
