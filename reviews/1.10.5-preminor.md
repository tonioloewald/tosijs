## Blockers

## Minor
- **(unverified, blast-radius) README.md still has 0 mentions of `withAttributes`.** The 1.10.5 CHANGELOG says "llms.txt and the README never mentioned withAttributes", but only llms.txt was fixed. README is the npmjs.com page and ships in the tarball, so the same misreading can happen through README. Not a blocker for a docs patch.
- **(release-manager spot-check, docs/dx) The new Component description drops `initAttributes`.** An agent reading llms.txt may conclude that `initAttributes` is deprecated. It is not: withAttributes emits it, and it is the only way to add attributes to an existing class. The description also leaves out the subclass caveat: new keys need `interface Sub extends ComponentAttrs<typeof Sub.initAttributes> {}` to be typed on `this`.

## Nits
- **(unverified, efficiency)** Suite time and build time are not recorded per release, so there is nothing to compare today's 17.05s against, and slow growth across releases would go unnoticed. This release cannot have slowed anything down: it adds no tests or build steps.
- **(unverified, blast-radius)** The fix is a one-off. Nothing links "a breaking entry in Migration/CHANGELOG" to "the Migration page description names it". That gap kept the 1.10.0 break out of llms.txt for five releases. Sibling projects that build llms.txt the same way (tosijs-ui) have the same gap.
